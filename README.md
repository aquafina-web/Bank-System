#Bank Management System

This is a user-friendly website where an user can add their account name and deposit or withdraw money! It works as a real bank system, offerung the same qualities. PS: The user's balance stays private.

This website was made because it connects website developing to a real life application and makes it easy for an user trying to deposit/withdraw money.

-> Step-by-step instructions on how to get it working:
1. Press the run button which appears in a triangular shape.
2. Enter your account name, and press enter.
3. Enter your initial bank acoount balance.
4. Enter the amount you want to deposit from your account.
5. Enter the amount you want to withdraw from your acoount.
6. Done! (Your account name and final balance will display in the output).
